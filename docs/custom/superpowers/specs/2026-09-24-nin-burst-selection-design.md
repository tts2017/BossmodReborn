# NIN バースト選択(先雷遁/先活殺の自動選択)と 7.5 精査 設計

2026-09-24。対象ブランチ nin-prekassatsu3rd-stability(`F:\bossmodreborn`)。作業は隔離コピー `F:\bmr_nin_iso` で行い、完了後に本体へ書き戻す(未コミット)。

## 目的

xan NIN(`BossMod/Autorotation/Standard/xan/Melee/NIN.cs`)について次を行う。

1. 7.5 までの威力変更を反映する(クライアント実データで照合)。
2. rDPS が最大になるようにスキル選択とローテーションを精査する。
3. 先雷遁(百雷銃の前に雷遁)と先活殺(百雷銃の前に活殺)を、その時点の状態から rDPS 比較で自動選択する。
4. 開幕は設定した最低 GCD 位置(毒盛・百雷銃それぞれ)を守り、以降は状態に応じてバースト GCD・スキルを調整する。
5. 事前チューニング規則にタイムライン等のヒントを加える方式も選べるようにする。

## 背景

- 出典の食い違い
  - erSharifst 7.5(https://www.ersharifst.com/2025/02/27/dsxcfgyh9io/): 先雷遁を採用。偶数分バーストで「活殺先 = 雷遁 2 + 雷獣 2、雷先 = 雷遁 1 + 雷獣 3 + コンボ 1」なので雷先の方が稼げる。活殺先は簡単でズレに強い。毒盛と百雷銃の間は必ず 2 GCD。
  - Game8 7.5(https://game8.jp/ff14/615096): 推奨 GCD 2.12。「開幕バースト(2毒盛り・3百雷銃)」= 先活殺。先雷遁版も併記。
  - The Balance(advanced guide、7.05): Extended Standard(先活殺系 + 最遅 weave)が通常強い。JP(先雷遁)は追加 GCD で六道が 1 回増える時に勝つ。百雷銃の実効は 16.25 秒、PK を窓の最後の GCD にしない。
  - 上位 200 ログ(tools/mnk_tuning、2026-05): 先活殺 183 / 先雷遁 17。
- 状態次第で優劣が入れ替わるので、固定規則ではなく状態からの比較で選ぶ。
- 現行コードの問題
  - 開幕の毒盛が `TargetMugLeft == 0` なら即使用で、開始 GCD の制約がない。
  - 先雷遁/先活殺の選択(`KassatsuFirstScore` / `RaitonFirstScore`)が固定加点式で、威力の比較になっていない。
  - `MudraCharges` が `ActionManager.Instance()` を直接呼ぶため、ゲーム外(ハーネス)で例外になる。
  - Goka Mekkyaku の威力定数が 600(実値 850)。口寄せ・六道の AoE 分岐点のコメントが旧威力のまま。
  - 百雷銃・毒盛のデバフは着弾遅延(1.29 / 1.07 秒)後に付くが、窓判定が `TargetTrickLeft` / `TargetMugLeft` だけなので、押下直後の約 1.3 秒間を「窓なし」と誤判定する。
  - 天地人が「印 0 チャージの時だけ」の条件で、出典の「氷晶の直後」とずれる。
  - NIN には威力計測のできるハーネスがない(tools/nin_real_harness は挙動チェックのみで、現行ソースとも不整合)。

## 用語

- 先雷遁(RF): 百雷銃の前に雷遁を撃つ型。偶数分は「毒盛 → (PK あり: 雷遁→PK / なし: コンボ→雷遁) → 百雷銃 → 雷獣(活殺・夢幻を weave) → 氷晶 → 天地人 …」。奇数分は「百雷銃 → コンボ 1 → 活殺・夢幻 → 氷晶 → 雷遁×2・雷獣×2」。
- 先活殺(KF): 百雷銃の前に活殺を撃つ型。偶数分は「活殺(百雷銃より前) → 毒盛 → 1〜2 GCD(PK 優先) → 百雷銃 → 氷晶 → 雷遁/雷獣/天地人 …」。奇数分は「活殺 → 百雷銃 → 氷晶 → 雷遁 …」。
- 確定行動: 案を固定する行動。RF は百雷銃前の雷遁の印押下、KF は百雷銃前の活殺押下(奇数分 RF は活殺なしの百雷銃押下)。
- 実効窓: 標的デバフ(毒盛・百雷銃)は押下時点で表示され、サーバー確定時(百雷銃 +1.29 秒、毒盛 +1.07 秒、リプレイ実測)に付け直される。ダメージ判定は押下時刻で行われるので、窓は押下から 16.29 秒 / 21.07 秒(判定は押下時刻)。着弾時刻判定ではない(当初案から変更、リプレイ 8 本・百雷銃 171 回で確認)。

## 開幕位置

- 下限として扱う。「N GCD 後」は、戦闘開始以降の自分の GCD(WS・忍術・天地人忍術を各 1、印とプリプル水遁は数えない)が N 回実行された後の weave 枠を指す。
- GCD 数は `Manager.LastCast` の SourceSequence の更新で数える(ゲーム内とハーネスで同じ)。
- 適用はそのプルの初回の毒盛・百雷銃だけ。戦闘 30 秒経過で解除(途中参加・開始直後のダウンタイムで詰まらないように)。
- Normal スタイルで百雷銃位置 ≤ 毒盛位置なら、百雷銃を毒盛 + 1 に補正。Ultimate 0 秒スタイルでは使わない。
- 選ばれた案で百雷銃が下限より後になる(RF は毒盛の 2 GCD 後)のは許容する。

## 選択器

### 入力 `NinBurstContext`

- 時間: 次 GCD まで、WS の GCD 長、アニメロック、ping(AnimationLockDelay)、レベル、各技の解放状態。
- 資源: 印チャージ数と次チャージまで、印の進行中状態、活殺(効果残り・CD)、天地人・命水・分身・夢幻の CD、PK Ready 残り、雷獣の数と残り、忍気、風纏、コンボ段、秘技、命水バフ、天理 Ready、隠形/隠れる。
- 窓: 毒盛・百雷銃の残りと CD(押下済み未着弾も含む)、PT シナジー(RaidBuffsIn/Left)、薬の残りと CD。
- 開幕: 経過 GCD 数、2 つの下限、初回か。
- ヒント(`MechanicHints` の選択に従う): 標的消失/復帰まで、強制移動、射程外、ダウンタイム中。

### 実装

- 計画器(A): 両案を模擬し、目的値の高い方を選ぶ。
- 事前規則(B): 実現可能性 → ヒント条件 → 調整済み条件式の順に判定。閾値は `NinBurstTuning` に置き、ハーネスの `nin-burst-sweep` で決める。
- 固定: 先雷遁 / 先活殺。
- 実現可能性は全実装で共通:
  - RF: 百雷銃前に印 1 チャージ、百雷銃前に GCD 枠 2 つ(偶数分)、活殺が百雷銃窓内に戻る。
  - KF: 活殺が百雷銃前に使え、その効果 15 秒のうちに氷晶まで届く。
  - 片方しか成立しなければその案に確定。両方不成立なら従来の汎用優先度。
- 事前計算の案(戦闘ごとの表)を差し込む口は `INinBurstSelector` で用意するが、今回は実装しない。
- Ultimate 0 秒スタイル(毒盛と百雷銃を同時)は従来どおり先活殺固定で、選択器を通さない。

### 目的値(rDPS)

- 自己威力 × 自己由来の倍率(百雷銃 1.10、毒盛 1.05、活殺 1.30、薬 1.06)+ 終端価値。
- PT シナジーは rDPS 上は付与者の取り分なので目的値に入れない。差が 20 未満の時の同点処理としてだけ、シナジー中の威力を比べる。
- 毒盛の PT 寄与は案で変わらないので比較に入れない(ハーネスの rDPS 指標には入れる)。

## 計画器モデル

- 現在(t=0)から「百雷銃窓の終わり(着弾基準)+ 1 GCD」まで模擬する。偶数分は毒盛窓の終わりも含める。
- GCD: WS は GCD 長、印 0.5、忍術 1.5、天地人は 1.0 / 1.0 / 1.5。weave 枠は「GCD の空き − 各アビのロック(0.6 + ping)」。
- 窓判定: 標的デバフ(毒盛・百雷銃)も自己バフ(活殺・薬)も PT シナジーも押下時刻で判定する。窓は押下から 16.29 秒 / 21.07 秒。
- 行動列: 百雷銃までは各案の具体形。百雷銃の後は共通の貪欲則(下記「窓内の順序」)。
- 終端価値: 印チャージ(雷遁 + 雷獣の上乗せ分、チャージ途中は按分)、雷獣(次の近接 WS 前に使える分)、忍気(六道換算、上限まで)、風纏(+100)、PK Ready、未使用の秘技・命水・天理(その技の威力)。
- ヒント: 消失中の行動は 0 とし、雷獣・活殺効果など期限付き資源は失効させる。射程外の間は近接 WS を不可とする。
- 揺れ防止: 仮決定は毎フレーム再評価するが、差が 20 未満なら切り替えない。

## 実行側

- 判断開始: 偶数分は毒盛の 1 GCD 前(開幕は下限の 1 GCD 前)、奇数分は百雷銃の 1 GCD 前。
- 固定: 確定行動を押した時。解除は百雷銃窓の終了、標的変更・消失、既存の再同期(Resyncing)。
- 窓の検出: `TargetTrickLeft` / `TargetMugLeft` は実効値(押下から確定までの間は「効果時間 + 確定遅延 − 経過」で補う)。計画器へ渡す「押下からの経過」は、その標的で窓が動いている時だけ値を持ち、前のバーストの押下は含めない(含めると開幕以外の全バーストが不成立になる欠陥があった)。
- RF: 百雷銃前の状態機械(PK あり: 雷遁→PK、なし: コンボ→雷遁)で 2 GCD を埋め、百雷銃は終端合わせで weave。活殺は百雷銃後の最初の GCD の weave。
- KF: 活殺は百雷銃より前、氷晶が効果 15 秒に収まる範囲で遅めに weave。百雷銃前の GCD はフィラーと PK。
- 窓内の順序(両案共通):
  - 活殺中は氷晶(AoE 2 体以上は劫火)を最優先。
  - 偶数分の天地人は氷晶の直後。ただし印が 2 チャージなら雷遁を 1 回先に撃つ。活殺中は使わない。窓内条件は「最初の忍術が窓内」で足りる(3 発すべてを求めると次の窓まで 120 秒 CD がずれ、窓外に漏れる 1 発の 10% より高くつく: +0.2%)。
  - 雷獣は次の近接 WS より前に使う。天地人をまたいで保持してよい。
  - 命水は天地人の直後(忍気が溢れない範囲)、その後に天理と是正/六道。
  - PK は窓の最後の GCD にしない(着弾 1.57 秒)。
- 百雷銃の weave 位置: 現行の終端合わせ遅延を維持し、GCD を遅らせない範囲で遅めにする。
- 薬: 偶数分は毒盛の 1 GCD 前(`ReadyIn(毒盛) ≤ GCD + GCD 長`)。百雷銃時に押すと百雷銃・氷晶の織り込みを取り逃す(ハーネス +1.0%)。
- 印チャージ: クールダウン群(20 秒 × 2)の経過から数える。ゲーム内の値と同じ。

## AoE 分岐点(Lv100)

- 活殺忍術: 劫火 850n vs 氷晶 1300 → 2 体以上で劫火。
- 六道系: 口寄せ 250n vs 六道 400 → 2 体以上で口寄せ。命水中は 3 体以上(500 < 550)。
- 是正系: 蝦蟇仙 400n vs 是正 700 → 2 体以上で蝦蟇仙。命水中は 3 体以上(800 < 850)。
- 通常忍術: 火遁 350n vs 雷遁 740 + 雷獣上乗せ → 3 体以上(現行どおり)。
- 近接コンボ: 実測で Lv90 以上は 4 体から範囲(3 体は単体 +5.2%、4 体は範囲 +0.2%、5 体 +4.0%)、Lv90 未満は 3 体から(Lv80 +1.2%、Lv70 +3.1%)。

## ハーネス

### 模擬器 `NinCombatState`

- ゲージ: 忍気・風纏を `NinjaGauge` 構造体から GaugePayload に書く。忍気の溢れを計上する。
- 印: 押下で Mudra ステータスの Param に 2 ビットずつ積む。印は GCD 0.5、チャージ群 20 秒 × 2(活殺中は消費しない)。
- 忍術: 押された忍術 AID と印の並びを照合し、不一致はうさぎとして計上して効果なし。活殺中の氷晶・劫火は活殺を消費し +30%。忍術 GCD 1.5。
- 天地人: 6 秒、Param の進行、順序ごとの変換、活殺中は使用不可、Lv100 で天理 Ready 30 秒。
- 雷獣: 雷遁で +1(最大 3、30 秒)、近接 WS の使用で消滅(消滅数を計上)。
- 分身: 5 回、WS ごとに追撃(近接/遠隔 160、範囲 80)と忍気 +5。PK には追撃しない。PK Ready 45 秒。
- 隠形: 水遁・風遁・天地人水遁で 20 秒。百雷銃と命水で消費。百雷銃は隠形/隠れるが必須。
- 毒盛・百雷銃: 標的デバフを押下時に付け、確定遅延(1.07 / 1.29 秒)後に付け直す。秘技 30 秒、是正/蝦蟇仙で消費。命水バフは六道/是正で消費。
- NIN の 15% ヘイストを Lv45 以上で同期(MNK の Greased Lightning と同じ方式)。
- 押下を `OpCastEvent` で発行する(`Manager.LastCast` と開幕 GCD 計数のため)。

### スコアラー `NinPotencyScorer`

- 威力は `NinPotency`(レベル別)。PotencyAudit でクライアント実データと一致を確認する。
- 標的デバフ(百雷銃 1.10、毒盛 1.05)、活殺 1.30、薬はいずれも押下時刻で判定。
- 指標: `potency`(自己、自己由来倍率のみ)、`party_dokumori`(毒盛の PT 寄与: 1450 威力/秒 × 5% × 窓内秒、PT シナジー中 ×1.5)、`rdps = potency + party_dokumori`、`buffed_potency`(PT シナジー中の威力、aDPS 参考)。
- NIN 指標: `kunai_potency`、`kunai_gcds`、`raiju_lost`、`rabbits`、`mudra_cap_s`、`ninki_overcap`、`rf_bursts`、`kf_bursts`、`opener_dok_gcd`、`opener_kunai_gcd`。
- トレースに百雷銃窓ごとの GCD 列を出す(計画と実行のずれの検出用)。

## 実装時の変更点と結果(2026-09-24)

- 分身: 忍気消費(六道系)と同優先度だと `ActionQueue.FindBest`(不安定ソート)で順序が不定になり、範囲時に分身が一度も出なかった。分身が押せて忍気が両方分ない間は通常の忍気消費を止める(溢れ回避の消費は止めない)。
- 奇数分の百雷銃: 次の偶数分の整列時刻を 2 秒以上過ぎるなら飛ばす規則があり、先雷遁で百雷銃が 2 秒遅れると次の奇数窓が丸ごと消えていた(2867 シナリオで 743 窓)。許容を 10 秒にした(5〜20 秒で結果同一、+0.7%)。
- 先雷遁の前半ペア: 2 手目の雷遁が「百雷銃直前の通常忍術抑止」で潰れていた(元コードからの欠陥)。ペアの雷遁と PK は抑止の対象外にし、整列開始時刻を過ぎたら打ち切る。印入力中は案を再判定しない。活殺が有効なら先雷遁は不成立(雷遁が活殺忍術に化ける)。隠形がペア後の百雷銃まで持たない時も不成立。
- 低レベル: 氷晶未習得なら活殺忍術を窓まで保留しない(保留中は印チャージが止まる)。開幕位置の下限は毒盛習得(Lv66)以降だけ適用。
- 不採用(A/B で改善なし): 計画器の CD 位相終端価値(−0.03%)、水遁準備リードの変更(8/10/14/16 秒)、分身・百雷銃の優先度引き上げ。
- 結果(timeline-combat-matrix 2867 シナリオ、Lv100、対 現行 NIN.cs、rDPS): 既定(計画器)+6.82%、PT シナジー付き +6.45%、消失ヒント付き +6.46%、timeline-matrix +4.40%、DMU +5.19%。先雷遁固定は短尺・ヒント無しで劣り(cm +5.81%)、途切れない長尺では勝つ(ヒント付き +6.78%、DMU +5.83%)。計画器は先活殺と同等で、先雷遁の長尺優位までは取れていない(未決)。事前規則は全 suite で先活殺以上。Lv30〜90、複数標的 1〜4、ランダム離脱、SkS 800 でも現行以上、他ジョブは完全一致。
- 既定の変更(2026-09-24 追試): 事前規則に「予告源が発信中で、百雷銃窓 + 1 GCD の間に消失予告がなければ先雷遁」を加え、既定を計画器から事前規則に変えた。計画器は先雷遁の長尺優位(ヒント付き 70〜250 秒で +0.15〜1.0%)を取れず、実行側に寄せた模擬(ペア型を毒盛押下時に決める)は全 suite で悪化した(cm −0.15%、matrix −0.59%)。事前規則は cm ±0、ヒント付き +0.24%(計画器比 +0.30%)、DMU +0.35% で計画器以上。ハーネスは予告源の存在を示すため、消失が lead 内に無くても空の snapshot を出し続ける(他ジョブの結果は不変)。ゲーム内で予告源が発信していない間は先活殺になる。
